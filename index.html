comfy-poster

comfy-poster is a small personal command-line tool that publishes short videos its owner creates with ComfyUI to the owner's own social accounts: YouTube Shorts, Instagram Reels, Facebook Page Reels and TikTok (as drafts).

It runs only on its owner's computer. It is not a hosted service, has no other users, and does not access anyone else's accounts or data.

How it works

  • Finished videos are placed in a local folder with a short description file.
  • At the scheduled time, comfy-poster uploads each video through the platform's official API, using sign-ins the owner granted to their own accounts.
  • Every post is labelled as AI-generated wherever the platform's API supports it.
